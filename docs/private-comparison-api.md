# 公众号订阅比价私有 API

该接口只供 `o614/gzhbot` 调用，不面向浏览器或第三方开放。Web 与公众号继续保持两个独立仓库。

## Cloudflare Pages 配置

在 Pages 项目的生产环境中添加：

- KV 绑定：`PRICE_COMPARE_KV`
- 加密变量：`PRICE_COMPARE_API_SECRET`

密钥至少使用 32 个随机字节，不写入仓库。公众号 Vercel 项目必须配置同一份密钥。

## Vercel 配置

公众号项目添加：

- `PRICE_COMPARE_API_URL=https://price.290935.xyz/api/apps/private`
- `PRICE_COMPARE_API_SECRET=<与 Cloudflare 相同的密钥>`

## 接口

所有接口只接受 `POST`，请求头包含 Unix 秒时间戳与 HMAC-SHA256 签名：

- `x-price-timestamp`
- `x-price-signature`

签名原文为：

```text
时间戳\n请求方法\nURL 路径\n原始 JSON 请求体
```

可用路径：

- `/health`：检查鉴权、KV 与快照状态，不触发抓取。
- `/search`：按名称、App ID 或 App Store 链接返回最多三个候选。
- `/compare`：读取快照或缓存；未收录 App 启动固定 20 区抓取。

## 缓存与降级

- 正常缓存 12 小时。
- 热门 App 最快每 3 小时后台刷新。
- 旧缓存最多兜底 7 天。
- 同一 App 的抓取使用短锁降低并发重复；单个地区失败不会终止其他地区。
- 无缓存的首次抓取最多等待约 2.8 秒，未完成返回 `202 pending`，后台继续抓取。
- 旧快照若缺少 Product ID，不作为完整结果返回；先以 `202 pending` 触发结构化目录刷新，避免丢失月付、年付或误配同名项目。
- 全局限流为每分钟 60 个签名请求，限流时优先使用已有缓存。
- 精选 App 与 Apple 官方服务直接复用网站快照；临时查询不会加入公开目录或价格日志。

Cloudflare KV 是最终缓存，公众号 KV 只保存三分钟会话、匿名运营聚合和热门判断。

## 套餐身份与匹配

套餐匹配只使用 Apple 官方数据或仓库内已核验的套餐定义，不从其他比价网站导入名称、Product ID 或价格。

匹配优先级：

1. 首选 Apple 官网自身使用的结构化 App 目录；以数值内购项目 ID（`salableAdamId`）作为跨地区唯一身份。
2. 同一 ID 还要校验 `offerName`、`subscriptionFamilyId` 和结构化计费周期；字段冲突时排除该地区，不用名称或价格补齐。
3. 结构化目录临时失败时才降级到统一 `?l=en` 的公开网页。唯一名称可以精确匹配；同名重复项目只保留美国锚点，其他地区标记为无法确认。
4. 不按页面顺序或价格高低配对同名项目，也不根据价格比例猜测月付、年付。
5. 同名但周期不同的套餐用月付、年付区分；同名、同周期且 Product ID 不同的项目才使用 `#1`、`#2`、`#3`，序号仅供用户选择，不参与跨地区匹配。

结构化目录属于 Apple 官网当前使用的页面数据入口，并非 Apple 承诺长期稳定的公开 API。因此每个地区独立失败、独立降级；目录异常不能中断其余地区，也不能被误判为该地区未上架。

私有 API 的套餐对象可包含：

- `productId`：仅在上游官方数据确实提供时出现。
- `matchMethod`：通常为 `product-id`；旧网页的唯一名称降级为 `exact-name`，供排错使用，不展示给公众号用户。
